# The Book Chapters and Architectural Spine

This directory contains the manuscript source files for the eleven substantive chapters and capstone of *Physical AI: Machine Learning Systems That Sense and Act*.

Each chapter lives in its own directory, with the main manuscript matching the directory name (`NN-slug/NN-slug.qmd`) and localized figures under `figures/`.
