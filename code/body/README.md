# body

The robot's physical layer: motors, speaker, mic, and camera, driven by the
`reachy_mini` SDK and wrapped as simple, readable "skills" (say, look, tilt,
wiggle, nod, shake, and behaviors built from them).

- Runs on the robot, or on a dev Mac over the network.
- Phase 0 (proven). The existing skills playground moves here.
- This is also the layer Maya eventually edits to program new tricks.
