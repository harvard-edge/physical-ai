# Authoring Packets

This directory contains versioned, accepted context for chapter production. It
is not manuscript prose.

| Packet | Status | Permitted use |
| --- | --- | --- |
| `CONTEXT-v1.yml` | Accepted | Foundation-wave research and chapter architecture |
| `CH01-AUTHORING-PACKET.md` | Packet red team passed; opening-cluster pilot authorized | Chapter 1 progressive drafting, transfer, and lab design |
| `CH01-SOURCE-PACKET.md` | Core source locations verified; bibliography cleanup pending | Chapter 1 claim qualification and citation audit |
| `CH01-REPRESENTATION-PACKET.md` | Composition briefs accepted; assets pending | Chapter 1 figures, tables, schema, and cumulative plate |
| `CH02-AUTHORING-PACKET.md` | Contract accepted; architecture candidate | Chapter 2 source, representation, and red-team work |

A packet authorizes only the work named in its status. Chapter 1's opening
cluster and provisional assets may now be developed in parallel. Full-chapter
acceptance still requires verified visual assets, bibliography cleanup, and a
red-team check of the resulting prose and figures.

New context enters this directory through a recorded version change. Raw agent
output, unreviewed drafts, and rejected alternatives do not silently become
authoritative context.
